# 세트 카운터 Pro — 결제 설정 안내

작성일: 2026-10-27 · 상태: 앱 코드 완료, App Store Connect 상품은 개발자 등록 후 생성

## 무료와 Pro

운동을 **하는** 기능은 무료, 운동을 **분석·관리·꾸미는** 기능은 Pro입니다.

| 영역 | 무료 | Pro |
|---|---|---|
| 운동 | 세트 카운트, 휴식 타이머·알람, 잠금 화면 알람, 운동 목록, 심박수(AirPods·블루투스) | Apple Watch 앱 (실시간 심박, 손목 알림) |
| 루틴 | 분할 루틴 순환, 아침 알림, 추천 루틴 (지난번 무게·횟수) | 내 루틴 편집, 다음 무게·횟수 자동 추천 |
| 기록 | 캘린더, 기록 보기·수정 | — |
| 통계 | 이번 주 요약, 운동한 날 차트 | 볼륨 차트, 운동별 1RM·볼륨 추이, 부위 밸런스, 운동 잔디, 개인 기록 보드, 유산소·체중 차트, 지난 기간 대비 증감 |
| 리포트 | 오늘 리포트, 이번 주(막 끝난 주) 리포트 | 지난 날짜·지난 12주 리포트, 지난주 대비 증감 |
| 다이어트 | 오늘 칼로리·BMR, 식사 추가, 오늘 식단, 체중 기록 (1·3개월) | 지난 날짜 식단, 내 음식 저장, 체중 1년 추세, BMI |
| 데이터 | 자동 저장, 백업·복원 | CSV 내보내기·가져오기, 운동 이름 관리 |
| 위젯·꾸미기 | 오늘의 루틴 위젯 (홈 화면) | 칼로리 위젯, 잠금 화면 위젯, 화면 모드·강조 색 |
| 배지 | 전부 | — |

Pro 기능은 숨기지 않고 흐리게 보여준 뒤 "Pro로 보기" 버튼으로 결제 화면을 엽니다. 구독이 끝나면 데이터는 그대로 두고 화면만 다시 잠깁니다.

## 상품 (App Store Connect에 똑같이 만들 것)

| 상품 ID | 종류 | 가격 | 메모 |
|---|---|---|---|
| `com.andykim.SetCounter.pro.yearly` | 자동 갱신 구독, 1년 | ₩22,000 | 구독 그룹 "Pro", 레벨 1, 7일 무료 체험 (신규 구독자용 프로모션) |
| `com.andykim.SetCounter.pro.monthly` | 자동 갱신 구독, 1개월 | ₩2,900 | 구독 그룹 "Pro", 레벨 2 |
| `com.andykim.SetCounter.pro.lifetime` | 비소모성 | ₩49,000 | |

상품 ID는 [ProStore.swift](../SetCounter/ProStore.swift)의 `ProPlan.productID`와 같아야 합니다. 가격은 App Store가 보낸 값을 그대로 표시하므로 코드를 고칠 필요가 없습니다.

## 개발자 등록 전에 테스트하기

1. Xcode에서 `SetCounter.xcodeproj`를 열고 SetCounter 스킴으로 실행합니다. 스킴에 [Config/SetCounter.storekit](../Config/SetCounter.storekit)이 연결돼 있어 진짜 결제 없이 결제창이 뜹니다.
2. 결제 기록 확인·환불·구독 만료: Xcode 메뉴 Debug → StoreKit → Manage Transactions.
3. 결제 없이 Pro 화면만 보려면: 설정 → 세트 카운터 Pro → 맨 아래 "테스트용 Pro 켜기" (Debug 빌드에만 있음).
4. 자동 테스트: `ProTests`가 같은 .storekit 파일로 상품 불러오기 → 연간 구매 → Pro 켜짐 → 거래 삭제 → Pro 꺼짐을 확인합니다.

## 출시 전 할 일

1. Apple Developer Program 가입 ($99/년)
2. App Store Connect → 계약/세금/금융에서 **유료 앱 계약** 동의, 은행 계좌·세금 정보 입력 (이게 끝나야 상품을 팔 수 있어요)
3. **App Store 소규모 사업자 프로그램** 신청 → 수수료 30% 대신 15%
4. 위 표대로 구독 그룹과 상품 3개 생성, 한국어·영어 표시 이름과 설명, 심사용 스크린샷(결제 화면)
5. 연간 상품에 7일 무료 체험 프로모션 추가
6. 첫 심사 때 앱과 상품을 **함께** 제출
7. Sandbox 테스트 계정으로 실제 기기에서 구매·복원·해지 확인

## 심사에서 보는 것

- 결제 화면에 기간·가격·자동 갱신 안내, 이용약관(Apple 표준 EULA)과 개인정보 처리방침 링크 — 들어가 있음
- "구매 복원" 버튼 — 결제 화면 아래에 있음
- 무료 체험 후 결제 금액을 버튼 근처에 분명히 표시 — 버튼 아래 안내 문구
- 구독 관리: Pro 사용 중이면 결제 화면에 "구독 관리" 버튼 (시스템 구독 관리 시트)

## 남는 돈 계산

판매가에서 부가세 10%와 수수료 15%(소규모 사업자)를 빼면 약 77%가 남습니다. 연간 ₩22,000 → 약 ₩17,000, 개발자 등록비는 연간 구독자 약 9명이면 메워집니다.
