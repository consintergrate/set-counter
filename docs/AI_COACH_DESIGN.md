# AI 코치 대화 — 설계 문서 (초안)

작성일: 2026-10-25 · 상태: 설계만, 구현 전

지금 앱의 "오늘의 코치"는 기기 안에서 도는 규칙 기반 안내입니다(`SetCounter/Coach.swift`). 무료이고 인터넷도 필요 없습니다. 이 문서는 그 위에 얹을 **대화형 AI 코치**의 설계입니다. 사용자가 "정체기인데 어떻게 해요?", "오늘 저녁 뭐 먹을까요?"처럼 물으면, 내 운동·식단 기록을 바탕으로 한국어로 답합니다.

---

## 1. 범위

**v1에서 할 것**
- 텍스트 대화 (답변이 실시간으로 써지는 스트리밍)
- 기록 요약을 함께 보내 개인화된 답변: 목표, 최근 4주 체중 추세, 주간 근력·유산소, 오늘 칼로리, 주요 운동 기록
- 빠른 질문 칩: "이번 주 루틴 짜줘", "정체기 탈출법", "오늘 남은 칼로리로 뭐 먹지?"

**v1에서 하지 않을 것**
- AI가 앱 데이터를 직접 바꾸기 (루틴 저장 같은 것은 v2에서 tool use로)
- 사진으로 식단 인식, 음성 대화

---

## 2. 왜 서버가 꼭 필요한가

Claude API 키를 앱 안에 넣으면 안 됩니다. 앱 파일은 누구나 풀어볼 수 있어서 키가 빠져나가고, 남이 내 키로 요금을 쓸 수 있습니다. 그래서 **키는 서버(프록시)에만** 두고, 앱은 그 서버와만 이야기합니다.

```
iPhone 앱 ──HTTPS──▶ 프록시 서버 ──HTTPS──▶ Claude API
  (키 없음)          (키 보관, 사용량 제한)     (api.anthropic.com)
     ◀── 스트리밍(SSE) 그대로 전달 ──┘
```

프록시가 하는 일:
1. **진짜 앱인지 확인**: Apple App Attest(`DCAppAttestService`)로 정품 앱에서 온 요청만 받음
2. **사용량 제한**: 기기별 하루 메시지 수(예: 무료 체험 5회, Pro 50회), 입력 길이 제한
3. **요청 조립**: 고정된 시스템 프롬프트 + 앱이 보낸 요약 + 대화를 합쳐 Claude에 전달
4. **기록 최소화**: 대화 내용은 로그에 남기지 않음 (횟수·토큰 수만 기록)

추천 호스팅: **Cloudflare Workers** (TypeScript, 무료 구간이 넉넉하고 스트리밍 응답 지원). 구현할 때는 공식 `@anthropic-ai/sdk`를 씁니다.

## 3. 모델과 비용

기본값은 **`claude-opus-5-5`**(Claude Opus 5.5), `output_config.effort: "low"`입니다. 대화형 코칭은 깊은 추론보다 친절하고 정확한 답이 중요해서 `low`부터 시작합니다(Opus 5.5의 기본 effort는 `medium`이라 명시적으로 지정).

| 모델 | ID | 입력 $/1M 토큰 | 출력 $/1M 토큰 | 캐시 읽기 |
|---|---|---|---|---|
| Claude Opus 5.5 (기본) | `claude-opus-5-5` | $4.00 | $20.00 | $0.20 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | $2.00 | $10.00 | $0.20 |
| Claude Haiku 5.5 | `claude-haiku-5-5` | $0.10 | $0.50 | — |

(2026-10 기준 Anthropic 직접 API 요금. Haiku 5.5는 입력 10만 토큰 이하 기준.)

**메시지 1개당 대략적인 비용** (시스템 프롬프트 1.5K 토큰 캐시됨 + 요약·대화 2.5K + 답변과 사고 토큰 600 가정, 추정치):

| 모델 | 1회 | 하루 5회 × 30일 (사용자 1명/월) |
|---|---|---|
| Opus 5.5 | 약 $0.022 (약 30원) | 약 $3.3 |
| Sonnet 5.5 | 약 $0.011 | 약 $1.7 |
| Haiku 5.5 | 약 $0.0006 | 약 $0.09 |

어떤 모델로 갈지는 직접 정하실 부분입니다. 바꾸기 전에 아래 6장의 평가 세트(한국어 질문 20개)로 답변 품질과 실제 비용을 나란히 재보는 걸 권합니다.

### 수익화와의 관계 (중요)
지금 계획은 "무료 + 1회 결제 Pro"인데, AI 코치는 **쓸 때마다 돈이 계속 나갑니다**. 1회 결제로는 오래 쓰는 사용자의 비용을 감당할 수 없으니 AI 코치만은 다음 중 하나로 가야 합니다.
- **월 구독**(예: 월 2,900원, 하루 50회까지), 또는
- **충전식 크레딧**(예: 100회 1,900원)

규칙 기반 코치, 주간 리포트 같은 기기 안 기능은 지금처럼 무료나 1회 결제 Pro에 두면 됩니다.

## 4. 요청 구조

프록시가 Claude에 보내는 요청 (Messages API, 스트리밍):

```http
POST https://api.anthropic.com/v1/messages
x-api-key: <서버에만 있는 키>
anthropic-version: 2026-10-21
anthropic-beta: server-side-fallback-2026-07-01
content-type: application/json
```

```json
{
  "model": "claude-opus-5-5",
  "max_tokens": 4000,
  "stream": true,
  "output_config": { "effort": "low" },
  "fallbacks": "default",
  "system": [
    { "type": "text", "text": "<고정 코치 프롬프트>", "cache_control": { "type": "ephemeral" } }
  ],
  "messages": [
    { "role": "user", "content": "<내 기록 요약 JSON>\n\n이번 주 루틴 짜줘" }
  ]
}
```

- **`thinking`은 보내지 않음**: Opus 5.5는 사고를 끌 수 없고(`disabled`는 400 오류), effort로만 조절합니다. 사고 과정은 기본적으로 화면에 나오지 않습니다.
- **`temperature` 같은 샘플링 값은 보내지 않음**: 이 API 버전에서는 400 오류입니다.
- **`max_tokens: 4000`**: 비용 상한 때문에 일부러 낮췄습니다(사고 토큰도 여기에 포함). 답이 잘리면(`stop_reason: "max_tokens"`) 올립니다.
- **`fallbacks: "default"`**: 안전 필터가 드물게 질문을 거절하면(`stop_reason: "refusal"`) 서버가 알맞은 다른 모델로 자동 재시도합니다. 기본으로 켜 두었고, 원치 않으면 빼면 됩니다. 그래도 거절되면 앱에 "이 질문에는 답하기 어려워요" 안내를 띄웁니다.

### 프롬프트 캐싱
- 시스템 프롬프트(코치 역할, 말투, 안전 규칙)는 **글자 하나 바뀌지 않게 고정**하고 `cache_control`을 붙입니다. 같은 프롬프트가 5분 안에 다시 쓰이면 캐시 요금($0.20/1M)만 냅니다.
- Opus 5.5는 **512토큰 이상**이어야 캐시됩니다. 더 짧으면 오류 없이 그냥 캐시가 안 됩니다.
- 날짜, 오늘 칼로리처럼 **매번 바뀌는 값은 시스템 프롬프트에 넣지 않고** 첫 user 메시지의 요약 JSON에 넣습니다. 시스템 프롬프트에 날짜를 넣으면 매번 캐시가 깨집니다.
- 캐시가 되는지는 응답의 `usage.cache_read_input_tokens`가 0보다 큰지로 확인합니다.

### 대화 기록 규칙
- 앞선 대화는 **고치거나 잘라내지 않고 뒤에 붙이기만** 합니다. Claude 응답의 content 블록(보이지 않는 사고 블록 포함)을 그대로 다음 요청에 돌려줍니다. 중간을 지우거나 고치면 캐시가 깨지고, 최근 계정은 400 오류가 날 수 있습니다.
- 대화가 길어지면 앞부분을 잘라내는 대신 **새 대화를 시작**하고, 이전 대화의 짧은 요약을 새 대화 첫 메시지에 넣습니다. 기본 단위는 "하루 1스레드".

### 스트리밍
- 프록시는 Claude의 SSE(Server-Sent Events)를 앱으로 그대로 흘려보냅니다.
- 앱은 `URLSession.bytes(for:)`로 줄 단위로 읽고, `content_block_delta`의 `text_delta`만 말풍선에 이어 붙입니다. `message_delta`에서 `stop_reason`을 확인합니다.

## 5. 앱에 보내는 데이터 (최소화)

원본 샘플이 아니라 **기기 안에서 만든 요약만** 보냅니다. 이름, 이메일, 기기 식별자는 보내지 않습니다.

```json
{
  "date": "2026-10-25",
  "profile": { "sex": "male", "age": 25, "heightCm": 172, "weightKg": 73.2 },
  "goals": { "goalWeightKg": 68, "weeklyLossKg": 0.5, "intakeKcal": 1500,
             "steps": 8000, "cardioMinPerWeek": 150, "strengthDaysPerWeek": 4 },
  "weightTrend": { "change14dKg": -0.5, "change90dKg": -1.6 },
  "thisWeek": { "strengthDays": 1, "sets": 2, "cardioMin": 0, "avgSteps": 8004 },
  "today": { "eatenKcal": 1770, "activeKcal": 356, "routinePart": "가슴·삼두" },
  "topLifts": [ { "name": "벤치프레스", "bestKg": 70, "e1rmKg": 93 } ],
  "muscleSets7d": { "chest": 14, "back": 6, "legs": 0 }
}
```

`Coach.swift`, `HealthData`, `Goals`에 이미 있는 계산을 재사용하는 `CoachContext` 빌더를 만들어 이 JSON을 만듭니다.

## 6. 시스템 프롬프트 방향 (요점)

- 역할: 사용자의 개인 운동·다이어트 코치. 해요체, 짧고 구체적으로(기본 3~6문장, 루틴 요청 시 목록)
- 제공된 기록 요약만 근거로 답하고, 데이터가 없으면 없다고 말함
- **안전 규칙**
  - 의사가 아님. 통증·부상·질환·약 관련 질문은 전문가 상담을 권함
  - 하루 섭취는 남성 1,500kcal / 여성 1,200kcal 아래로 권하지 않음 (앱의 `Goals.intakeTarget` 하한과 같음)
  - 급격한 감량, 단식, 보충제 용량 지시는 하지 않음
  - 섭식 장애가 의심되는 말에는 비난 없이 도움받을 곳을 안내
- 숫자 단위는 사용자 설정(kg/lb)을 따름

**평가 세트**: 실제로 받을 법한 한국어 질문 20개(루틴, 정체기, 식단, 부상, 위험한 다이어트 요청 등)와 각각의 "좋은 답의 조건"을 먼저 적어 두고, 모델·effort·프롬프트를 바꿀 때마다 같은 세트로 비교합니다.

## 7. 개인정보와 App Store 심사

- **명시적 동의 화면**: 첫 대화 전에 "어떤 정보가(기록 요약), 어디로(우리 서버를 거쳐 Anthropic의 Claude), 왜(답변 생성)" 가는지 보여주고 동의를 받습니다. 설정에서 언제든 끌 수 있게 합니다.
- App Store 심사 지침 5.1.2(i)은 개인 데이터를 제3자 AI와 공유할 때 이를 알리고 명시적 동의를 받도록 요구하고, 5.1.3은 건강 데이터를 광고·마케팅에 쓰지 못하게 합니다. 제출 전에 최신 지침을 다시 확인합니다.
- 개인정보 처리방침과 App Store "앱 개인정보" 항목에 다음을 추가합니다: 건강·피트니스 데이터를 앱 기능 목적으로 외부 처리업체(Anthropic)에 전송, 신원과 연결하지 않음, 광고에 쓰지 않음. Anthropic API의 데이터 보존 정책을 확인해 방침에 적고 링크합니다.
- 프록시는 대화 본문을 저장하지 않습니다.

## 8. 앱 쪽 구성 (구현 시)

| 구성 | 역할 |
|---|---|
| `CoachChatView` | 말풍선 목록, 입력창, 스트리밍 중인 답, 빠른 질문 칩 |
| `CoachContext` | 기기 안 데이터를 위 5장의 요약 JSON으로 변환 |
| `CoachClient` | 프록시 호출, SSE 파싱, 거절·한도 초과·네트워크 오류 처리 |
| 동의 화면 | 7장의 내용, 동의 여부는 `@AppStorage` |
| Pro 확인 | 구독(또는 크레딧) 상태에 따라 하루 한도 표시 |

홈의 "오늘의 코치" 카드에 "코치에게 물어보기" 버튼을 두어 대화로 들어가게 합니다.

## 9. 진행 순서

1. **평가 세트 작성 + 모델 비교** (코드 없이, 질문 20개로 품질·비용 측정) — 반나절
2. **프록시** (Cloudflare Worker: App Attest 확인, 한도, 스트리밍 전달) — 1~2일
3. **앱 대화 화면 + 동의 화면** — 2일
4. **구독/크레딧 결제(StoreKit 2)** — App Store 유료 등록($99) 이후
5. v2: tool use로 "이 루틴 저장해줘" 같은 동작 (`strict: true` 스키마, `tool_choice`는 `auto`)

사전 준비: Anthropic Console 계정과 API 키, 사용 한도(월 지출 상한) 설정, Cloudflare 계정.
